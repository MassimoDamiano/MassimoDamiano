## 👨‍💻 About Me

I'm a software developer from Argentina focused on mobile and backend development.

I enjoy building complete applications, from mobile interfaces to backend services and REST API integrations. Through my projects, I have worked with Flutter, native Android development, Kotlin, Java, ASP.NET Core and C#.

I have experience implementing:

- Mobile applications with Flutter and native Android.
- REST API consumption and JSON processing.
- Backend services with ASP.NET Core.
- Local persistence with SQLite.
- State management with Provider and StateFlow.
- Asynchronous programming with Kotlin Coroutines.
- Unit and instrumented testing.
- Git and GitHub workflows.
- Continuous deployment with GitHub Actions and Azure.

I'm currently strengthening my Android development skills while continuing to learn software architecture, testing and backend development.
